### IV.1. Estado del proyecto

Durante este sprint el Proyecto Intermodular ha recibido mejoras en dos frentes:

- **Maquetación y diseño:** Gracias a las nuevas técnicas de Bootstrap aplicadas desde el módulo DIW, se ha mejorado la estructura visual del comparador y la tienda fake, haciéndolos más responsivos y consistentes con las directrices de usabilidad trabajadas.
- **Funcionalidad cliente:** Con la introducción de React desde el módulo DWEC, se ha empezado a integrar componentes dinámicos que mejoran la experiencia de usuario sin depender de recargas de página.
