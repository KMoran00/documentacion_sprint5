## III. Desarrollo WEB en entorno Cliente

### III.1. Introducción

Durante este sprint, el trabajo en el módulo de Desarrollo en Entorno Cliente ha abarcado tres frentes principales: continuar afianzando el uso de React como framework del lado del cliente, llevar a cabo el testing del Proyecto Intermodular, y elaborar un manual de instrucciones de la tienda, el comparador y el backoffice. React es la tecnología principal de este módulo y la que se aplica directamente al proyecto del curso.

### III.2. React

#### III.2.a. Conceptos trabajados

Continuar profundizando en React como framework de desarrollo en el lado del cliente. Los conceptos principales trabajados durante este sprint han sido:

- Estructura de un proyecto React y uso de JSX.
- Componentes funcionales y cómo dividir la interfaz en piezas reutilizables.
- Gestión del estado local con el hook `useState`.
- Efectos secundarios y peticiones asíncronas con `useEffect`.
